# IKIGAI Trading Bot

Elliott Wave + Fibonacci торговый бот для Bybit.

Автоматически сканирует топ-20 криптовалют, находит волновые паттерны и генерирует торговые сигналы по 3 сетапам:

- **Setup A** — Zigzag + Breakout (продолжение тренда после коррекции ABC)
- **Setup B** — Ending Diagonal / Клин (разворот на окончании клина)
- **Setup C** — Triangle + Breakout (импульс после пробоя треугольника)

## Установка на Mac с нуля

### 1. Установите Homebrew (если ещё нет)

Откройте Terminal (`Cmd + Space` → "Terminal") и выполните:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

### 2. Установите Python 3.11+

```bash
brew install python@3.12
```

Проверьте:

```bash
python3 --version
# Python 3.12.x
```

### 3. Установите Git (если нет)

```bash
brew install git
```

### 4. Склонируйте репозиторий

```bash
git clone https://github.com/grayson8geraldo/ikigai.git
cd ikigai
```

### 5. Создайте виртуальное окружение

```bash
python3 -m venv venv
source venv/bin/activate
```

> После активации вы увидите `(venv)` в начале строки терминала.

### 6. Установите зависимости

```bash
pip install -r requirements.txt
```

### 7. Настройте конфигурацию

```bash
cp .env.example .env
```

Откройте файл `.env` в любом текстовом редакторе:

```bash
nano .env
# или
open -e .env
```

**Для бумажной торговли (без реальных денег)** — ничего менять не нужно, всё работает из коробки.

**Для реальной торговли** — вставьте API ключи Bybit:

```
BYBIT_API_KEY=ваш_ключ
BYBIT_API_SECRET=ваш_секрет
TRADING_MODE=live
```

> Ключи API получаются на https://www.bybit.com → Account → API Management.
> Включите только "Trade" permission, IP-ограничение обязательно.

## Запуск

### Один скан (найти сигналы сейчас)

```bash
python main.py
```

### Непрерывное сканирование (каждые 15 минут)

```bash
python main.py --loop
```

### Своя частота сканирования (каждые 5 минут)

```bash
python main.py --loop --interval 5
```

### Автоматическая торговля (бумажная)

```bash
python main.py --loop --trade
```

> Бот будет автоматически открывать позиции по найденным сигналам.

### Посмотреть текущие позиции и статистику

```bash
python main.py --status
```

## Настройки (.env)

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `TRADING_MODE` | `paper` | `paper` = симуляция, `live` = реальная торговля |
| `PAPER_DEPOSIT` | `150` | Начальный баланс для бумажной торговли ($) |
| `LEVERAGE` | `5` | Максимальное плечо |
| `RISK_PER_TRADE` | `0.08` | Риск на сделку (8%) |
| `MAX_POSITIONS` | `3` | Макс. одновременных позиций |
| `MIN_RR_RATIO` | `3.0` | Минимальное соотношение R:R |

## Как это работает

1. **Сканирование** — бот загружает свечи по 20 монетам с Bybit (таймфреймы: 1D, 4H, 1H)
2. **Анализ волн** — находит свинги, строит волны Эллиотта (импульсы, зигзаги, треугольники, диагонали)
3. **Детекция сетапов** — проверяет каждый паттерн на соответствие 3 сетапам стратегии
4. **Генерация сигналов** — рассчитывает вход, стоп-лосс, цели по Фибоначчи
5. **Риск-менеджмент** — проверяет R:R, лимиты позиций, дневные убытки
6. **Исполнение** — в paper mode симулирует сделки, в live mode ставит ордера на Bybit

---

## Безопасность

- **Бумажная торговля по умолчанию** — бот НЕ торгует реальными деньгами, пока вы явно не включите `TRADING_MODE=live`
- **Kill-switch** — автоматически останавливается после 3 убытков подряд или потери 20% за день
- **Лимит позиций** — максимум 3 одновременных позиции
- **Файл `.env` не попадает в git** — ваши ключи в безопасности
